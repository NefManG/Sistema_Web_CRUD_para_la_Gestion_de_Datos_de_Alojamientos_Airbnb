# Sistema Web CRUD para la Gestión de Datos de Alojamientos Airbnb

## Descripción

Este proyecto consiste en el desarrollo de una aplicación web orientada a la gestión y consulta de datos de alojamientos Airbnb. La información será obtenida a partir de un dataset en formato JSON e importada en una base de datos MongoDB.

La aplicación permitirá interactuar con los datos mediante operaciones CRUD, utilizando Python para el desarrollo del backend y una interfaz web para la visualización y administración de los alojamientos.

## Objetivo

Desarrollar una aplicación web que permita gestionar información de alojamientos Airbnb almacenada en MongoDB mediante operaciones CRUD: crear, consultar, actualizar y eliminar registros.

## Tecnologías previstas

- Python
- FastAPI
- MongoDB
- PyMongo
- React
- Vite
- Git
- Visual Studio Code

## Estructura del proyecto

El proyecto estará organizado inicialmente en tres componentes principales:

- `backend/`: contendrá la lógica de la aplicación desarrollada en Python y la comunicación con MongoDB.
- `frontend/`: contendrá la interfaz web mediante la cual el usuario interactuará con el sistema.
- `dataset/`: contendrá el archivo JSON utilizado para importar los registros de alojamientos en MongoDB.
